Student Data Management System

A simple Student Data Management System developed in C that allows administrators to manage student records efficiently.

#Features
Add Student
Update Student
Delete Student
Search Student by ID or Name
Generate Student Report
File Handling using students.txt
Separate Admin and Student Menu
